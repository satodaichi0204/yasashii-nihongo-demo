# 教室用「やさしい日本語＋多言語」表示（デモ版）

先生の指示を、**原文 → やさしい日本語 → 2言語の翻訳** にして、先生が確認したものだけを、拡張ディスプレイの**児童向けの画面**に表示するWebアプリのデモです。

- **APIキーを使いません。サーバーもありません。** すべてブラウザの中で動きます（費用0円）。
- 生成AIによる本物の変換はしていません。画面では「見本」「簡易変換」「参考訳」と表示しています。
- 中心は **意味の取りこぼしの照合** です。やさしい日本語にするときに、否定、順序、数量、条件、教科の用語、指示語、言い直しを落とすと警告が出て、先生が直すか内容を確認するまで、児童向けの画面に出せません。
- **用語カード**：今の指示に出てきた教科の用語を、ふりがな、やさしい説明、母語の訳と一緒に児童向けの画面に並べます。

## 構成

| 役割 | 技術 |
|---|---|
| 画面 | Vite ＋ TypeScript（strict）。フレームワークは使わない |
| 音声認識 | ブラウザ標準（Web Speech API, ja-JP）。マイクの接続状態と入力音量は Web Audio API |
| 翻訳 | 見本は参考訳。それ以外は Chrome の Translator API（ブラウザの中で動く翻訳。使える環境だけ） |
| 2つのウィンドウの連動 | BroadcastChannel（届かない環境では postMessage） |
| 拡張ディスプレイ | Window Management API（使えて、許可された場合） |
| 保存 | 用語集と定型文はブラウザの中（localStorage）だけ |
| テスト | Vitest |

```
src/
  adapters/   差し替えられる部品（音声認識、やさしい日本語化、翻訳）。同じ形の差し込み口（types.ts）
  checker/    意味の取りこぼしの照合（rules.ts、checker.ts）、翻訳の照合、精度の計算（metrics.ts）
  glossary/   用語集と定型文の保存、用語カード
  data/       見本20件（samples.json）、テスト用の追加データ（checker-cases.json）、用語集、言い換えの辞書、言語の一覧
  teacher/    教師用の画面。session.ts が「確認前は表示しない」などの規則（画面から切り離してテスト）
  student/    児童向けの画面
  channel/    2つのウィンドウの連動
```

## 起動

```bash
npm install
npm run dev        # 開発用（http://localhost:5173）
npm test           # 照合、簡易変換、翻訳の照合、画面の流れの規則のテスト
npm run lint
npm run build      # dist/（公開用）と dist-single/index.html（1ファイル版）
```

1ファイル版は `dist/yasashii-nihongo-demo-1file.html` としても出力し、公開URLからダウンロードできます。
ファイルを直接開くと、マイク、音声認識、ブラウザ内の翻訳、別ウィンドウとの連動が動かない場合があります。

## 写真について

ホームの写真は、フリー素材「[ぱくたそ](https://www.pakutaso.com/)」の写真です（モデルを使用したイメージ写真）。
素材の再配布にあたるため、このリポジトリには入れていません（`public/photos/` は `.gitignore` で除外）。
公開URLには、Vercel CLI で直接アップロードしています。写真がない環境では、写真の場所は空白になり、ほかの表示はそのまま動きます。

## データの追加の仕方

- **見本の指示**：`src/data/samples.json` に1件足します。
  - `easyRuby` は正しいやさしい日本語で、`[漢字|よみ]` の形でふりがなを付けます。
  - `mistakes` は、AIがよく起こす間違いの例2つと、落とした要素（`drops`）です。
  - `translations` は参考訳、`elements` は守るべき要素（照合の正解）です。
  - 足すと、テストと「検証結果」のページの数字に自動で入ります。
- **テスト用の追加データ**：`src/data/checker-cases.json` に、原文、変換、落とした要素（`expect`）を足します。
- **用語集の初期データ**：`src/data/glossary.json`。
  - `aliases` は「よくある別の訳」です。翻訳の中で見つけたら、学校で決めた訳に置き換えます。
  - 画面の「教科の用語集」で追加、修正した分は、ブラウザの中に保存されます。
- **言語**：`src/data/languages.ts` に1行足します。
- **言い換えの辞書**：`src/data/paraphrase.ts`。数字、否定、条件、順序の言葉と、用語集の言葉は入れません。
